
# Hello World Node.js

My first Node.js project using JavaScript and Git.

## Requirements
- Node.js
- Git

## How to Run

Open the terminal and run:

```bash
node hello.js
```

## Custom Greeting

You can enter your own name:

```bash
node hello.js Kalindri
```

## Example Output

Hello, Kalindri! Welcome to Node.js.
